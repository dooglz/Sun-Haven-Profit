# Sun Haven Profit

An offline recipe and resale lookup for Sun Haven.

Download [index.html](https://raw.githubusercontent.com/dooglz/Sun-Haven-Profit/main/index.html) and open it in a browser. Everything the tool needs is included in that file.

- **Item lookup** shows resale values and recipes for fish, crops, and forageables.
- **Profitability** compares recipes by percentage gain, profit per in-game crafting hour, or estimated profit per minute of hands-on work.
- **Quick Sell** shows which fish and forageables are worth crafting, with filters by region.

Recipe and item data are adapted from the [Sun Haven Wiki](https://sunhaven.wiki.gg/wiki/Guide:Crafting_Profit_Calculator) under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The page lists the source tables and calculation assumptions.
